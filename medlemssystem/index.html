Personvern: Klopp AS er databehandler

Klopp AS er databehandler, ikke behandlingsansvarlig, for medlemsdata. Foreningen som bruker tjenesten er behandlingsansvarlig, jf. GDPR artikkel 28. Se personvernerklæringen.

Ofte stilte spørsmål

Hva er forskjellen på Regweb og Medlem123?

Regweb og Medlem123 er det samme underliggende medlemssystemet. Forskjellen er hvem som drifter det: med Regweb administrerer foreningen medlemsregisteret selv, mens Klopp AS gjør det på foreningens vegne med Medlem123. Klopp AS håndterer da kun henvendelser som gjelder medlemmene, for eksempel kontingent og betalingsstatus.

Hvem er behandlingsansvarlig for medlemsdataene?

Foreningen som bruker tjenesten er behandlingsansvarlig for sine egne medlemsdata. Klopp AS er databehandler, jf. GDPR artikkel 28.

Hvor lagres dataene i Regweb og Medlem123?

Alle data lagres på norske servere. All utvikling, drift og support skjer i Norge.

Hva er XReg?

XReg er en frittstående verktøykasse som kobler seg til foreningens eksisterende medlemssystem via API, blant annet brukt som Regwebs egen «Din side»-portal.
